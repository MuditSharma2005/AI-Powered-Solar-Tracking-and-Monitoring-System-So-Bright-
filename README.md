# AI-Powered-Solar-Tracking-and-Monitoring-System-So-Bright-
So Bright is an AI-powered Solar Tracking and Monitoring System designed to improve solar energy generation through intelligent tracking, real-time monitoring, and data-driven predictions. The system combines IoT hardware, sensors, microcontrollers, web technologies, and Machine Learning to create a smart solar energy management platform.

The hardware system uses LDR sensors to detect the direction and intensity of sunlight. Based on the sensor readings, the system automatically adjusts the position of the solar panel using servo motors, ensuring that the panel is oriented toward the direction of maximum sunlight.

The system also collects real-time data such as sunlight intensity, solar panel position, weather conditions, temperature, and energy generation. This data can be transmitted through an IoT-enabled system and displayed on a web-based dashboard for continuous monitoring and analysis.

Using Machine Learning and weather forecast data, the platform can predict expected solar energy generation for upcoming days. It can also provide optimal angle recommendations, efficiency analysis, performance insights, and graphical visualisations to help users understand and improve solar panel performance.
